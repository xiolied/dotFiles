# Dotfiles

A lightweight, minimal Linux desktop environment setup.

## System Components

| Component | Software |
| :--- | :--- |
| **Status Bar** | Waybar |
| **Application Launcher** | Fuzzel |
| **Terminal Emulator** | Foot |
| **Notification Daemon** | Dunst |
| **Volume indicator** | SwayOSD |
